# HerSfar Website - Vercel Ready

This is a Next.js + Tailwind prototype for the HerSfar public website.

## Deploy on Vercel

1. Upload this folder to GitHub.
2. Go to Vercel.
3. Import the GitHub repository.
4. Click Deploy.

## Local Run

```bash
npm install
npm run dev
```

Open:

```bash
http://localhost:3000
```
